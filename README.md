🎓 Student Grade Checker

A simple web app built with Python and Streamlit that helps students calculate their total marks, average, grade, and overall performance status.

✨ Features

- Enter your name.
- Choose between 1 and 10 subjects.
- Enter marks out of 100 for each subject.
- Automatically calculate total marks and average.
- Assign a grade from A to E.
- Display a performance status based on the average.
- View results in a clean, easy-to-read layout.

🛠️ Technologies Used

- Python
- Streamlit
- Git and GitHub

🚀 How to Run Locally

1. Install Python on your computer.

2. Install Streamlit by running:
   
   pip install streamlit

3. Clone this repository and open the project folder.

4. Run the app using:
   
   streamlit run src/app.py
